# Eunoia — Design Document

*"Beautiful thinking" — a personal knowledge visualization tool*

## Problem

Existing tools like BirdsEyes attempt to map your intellectual interests but fall short:
- Surface-level interest extraction with no real depth
- Generic, AI-slop feel — vague marketing over actual utility
- Auto-generated UI that lacks craft and polish
- Connections between interests are superficial (just a line on a graph)
- No meaningful way to discover bridging paths between disparate domains

## Vision

Eunoia is a personal knowledge universe. Your interests exist as 3D particle clouds in space — dense at the core where you're deeply engaged, diffuse at the edges where domains start bleeding into each other. You orbit, zoom, and explore. When you want to connect two distant interests, you enter Bridge Mode and watch the clouds drift toward each other, revealing a new intersection zone of topics that link them together.

The system has *taste*. It doesn't give you Wikipedia taxonomies — it recommends like a deeply knowledgeable, opinionated polymath friend. It surfaces the unexpected connections, the foundational mathematics, the cultural discourse, the contrarian voices, the seminal works worth your time.

## Core Features (v1)

### 1. Manual Input

Users add interests through a unified input panel:
- **Books** — title + author
- **YouTube** — video links
- **Music** — album/track names
- **Articles** — plaintext paste
- **PDFs** — file upload
- **Raw interests** — just type a topic

The LLM parses each input, extracts core topics and themes, and generates nodes in the knowledge graph.

Future iterations will add direct integrations (Goodreads, YouTube API, Spotify, Apple Podcasts, Pocket, Instapaper, browser bookmarks).

### 2. 3D Cloud Visualization

Each interest domain is a **particle cloud/nebula** in 3D space.

**Cloud structure:**
- **Dense core** — deepest sub-interests, tightly clustered particles, vivid color
- **Mid-density ring** — related sub-topics explored or system-mapped
- **Diffuse periphery** — fringe topics, fading opacity, domain edges

**Visual language:**
- Each domain gets a distinct hue (ML = deep blue, Philosophy = amber, Music = magenta, etc.)
- Particle density and brightness encode depth of engagement — explicitly added items are brighter, AI-generated expansions are more subtle
- Subtle ambient particle drift so the scene feels alive
- Thin luminous filaments between closely related nodes within a cloud

**Camera and navigation:**
- Default: orbiting full universe from a distance
- Scroll to zoom into a specific cloud → individual nodes visible
- Click a node → side panel with knowledge tree and resources
- Trackpad/mouse drag to orbit, pinch to zoom

**UI overlay (minimal):**
- Floating search bar to jump to any interest
- Collapsible input panel for adding content
- Side panel for detail views on node selection
- Bridge Mode toggle button
- No heavy chrome — the 3D scene is the UI

### 3. Deep Exploration (Knowledge Trees with Taste)

Clicking a node opens a side panel with a multi-dimensional knowledge tree. Not just a technical taxonomy — exploration across six dimensions:

- **Foundations** — underlying math, theory, first principles (e.g., for ML: linear algebra, probability theory, information theory)
- **Taxonomy** — sub-field breakdown, going deep enough to be genuinely useful
- **Thinkers & Voices** — key people, contrarians, historians, practitioners with unique perspectives
- **Cultural Impact** — how the field affects art, society, politics, economics; the broader discourse
- **Adjacent Surprises** — unexpected connections a curious polymath would know but a textbook wouldn't mention
- **Controversies & Open Questions** — where the field is contested, uncertain, or evolving

**The "taste" system:**

The LLM prompt is crafted to behave like a well-read polymath friend:
- Prefer specific, opinionated recommendations over exhaustive lists
- Surface unexpected, cross-disciplinary connections by default
- Avoid generic descriptions — every piece of context should tell you something you didn't know
- Prioritize primary sources and seminal works over summaries
- Include *why* something is worth your time, not just *what* it is

**Resource curation per node:**
- Books & papers (with specific chapter/section recs when relevant)
- Videos & lectures
- People to follow / read
- Essays & articles
- Ranked by relevance and quality, not volume

Resources are generated by the LLM on first exploration, then cached. Users can upvote/dismiss to refine taste over time.

### 4. Bridge Mode

A dedicated interaction mode for discovering connections between disparate interests.

**Flow:**
1. Toggle Bridge Mode via UI button — visual indicator that you're in bridge mode
2. Click first cloud → visual highlight
3. Click second cloud → both clouds gravitationally drift toward each other in 3D space
4. A new intersection zone emerges where particles from both clouds overlap, blending colors
5. Bridge topics populate as new nodes in the intersection zone
6. Click any bridge node → side panel shows it framed as a connection point between the two domains
7. Option to "adopt" a bridge interest permanently into your graph
8. Exit Bridge Mode to return to normal exploration

**Example:** ML + Philosophy → intersection zone surfaces: Philosophy of Mind, Computational Theory of Mind, Ethics of AI, Algorithmic Bias, Judea Pearl's Causality, Chinese Room Argument, Embodied Cognition, etc.

### 5. Persistent Knowledge Graph (Hybrid AI)

**Architecture:**
- LLM calls (Claude API) for initial generation: knowledge tree expansion, bridge interest discovery, resource curation
- Results cached into the knowledge graph immediately
- Repeated queries are instant — no re-generation
- Graph enriches over time as users explore more
- A carefully crafted "taste" system prompt ensures consistent quality

**Data model:**
- **Interest nodes** — with depth levels and dimensional branches
- **Resource nodes** — books, papers, videos, people, linked to interests
- **Bridge edges** — computed connections between disparate domains
- **User engagement data** — which interests are explicitly added vs. AI-suggested, upvotes/dismissals

## User Flows

### Adding Interests
1. Open input panel → type/paste content
2. LLM parses input, extracts topics and themes
3. New nodes appear in 3D space — joining existing cloud or seeding new one
4. Particles coalesce into position with animation

### Exploring an Interest
1. Click node in 3D space → side panel opens
2. Interest name + one-line context ("why this matters")
3. Multi-dimensional knowledge tree below
4. Each branch expandable — deeper levels generated on demand, cached
5. Resources appear inline within each branch

### Bridging Two Interests
1. Toggle Bridge Mode
2. Click first cloud → highlighted
3. Click second cloud → clouds drift toward each other
4. Intersection zone emerges with bridge topics
5. Click bridge node → side panel with connection context
6. Adopt or dismiss bridge interests
7. Exit Bridge Mode

### Free Exploration
1. Orbit universe, zoom into clouds, browse periphery
2. Periphery nodes are AI-suggested expansions — dimmer, adoptable or dismissable
3. System periodically suggests new periphery nodes as graph grows

## Tech Stack

- **Frontend:** Next.js + React Three Fiber (R3F) for 3D visualization
- **3D rendering:** Three.js via R3F, custom shaders for cloud/nebula aesthetic
- **Backend:** Next.js API routes
- **Database:** PostgreSQL for user data + Neo4j (or lightweight graph store) for the knowledge graph
- **AI:** Claude API for generation with carefully crafted taste prompts
- **Styling:** Minimal UI overlay — dark theme to complement the 3D nebula aesthetic

## Not in v1

- Social features (sharing knowledge clouds publicly — future consideration)
- Direct platform integrations (Goodreads, YouTube API, Spotify, etc.)
- Account system / auth (local-first for v1)
- Mobile app

## Design Principles

1. **Taste over completeness** — opinionated polymath, not encyclopedia
2. **Depth over breadth** — multidimensional exploration, not surface-level taxonomy
3. **The 3D scene is the UI** — minimal chrome overlay
4. **AI generates, graph persists** — hybrid intelligence that improves over time
5. **Craft matters** — every animation, color choice, and interaction should feel intentional
